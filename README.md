# Summary

ParCoLab is a treebank of Serbian based on literary texts. It was originally developed between 2014 and 2018 (original corpus available here). 


# Introduction

ParCoLab is based on two works of fiction: "Bašta, pepeo" by Danilo Kiš and "Testament" by Vidosav Stevanović. It was originally annotated in a language-specific annotation scheme (original corpus available [here](https://github.com/aleksandra-miletic/serbian-nlp-resources)). The conversion to UD was done semi-automatically, using conversion scripts, followed by extensive manual checks and corrections. The corpus was developed as part of the [ParCoLab](https://parcolab.univ-tlse2.fr/en/) project.
